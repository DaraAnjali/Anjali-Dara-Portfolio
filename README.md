# Anjali Dara — Portfolio

React + Vite + Tailwind CSS personal portfolio.

## Run locally

1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Build for deployment

Run `npm run build`. Deploy the `dist` folder to Netlify, or import the repository into Vercel (framework: Vite).

## Customize

- Update project details, skills, and links in `src/main.jsx`.
- Edit theme styling in `src/style.css` and `tailwind.config.js`.
- Replace `public/profile.png` with a new portrait if needed.
- Replace `public/Anjali_Dara_Resume.pdf` to update the downloadable resume.

The contact button opens the visitor's email application. No backend is required.
